# Professional Mortgage Solutions Pty Ltd — Static Website

## Folder structure
```
professional-mortgage-solutions-site/
├─ index.html
├─ styles.css
├─ script.js
└─ assets/
   ├─ logo-transparent.png
   ├─ favicon.png
   ├─ prabhat-silwal.jpg
   ├─ prabhat-silwal.webp
   ├─ hero-bg.jpg
   ├─ hero-bg.webp
   ├─ logo-original.jpg
   └─ photo-original.jpg
```

## Quick start (local)
- Open `index.html` in a browser, or
- Use VS Code → **Live Server** extension (recommended) for automatic refresh.

## Make it live (recommended)
- **Netlify / Vercel / GitHub Pages** all work well.
- Update the placeholder phone number and any licence/ABN text in `index.html`.
- The contact form is a static `mailto:` fallback. For production, switch it to **Netlify Forms** or **Formspree**.

## Images
- `assets/hero-bg.jpg` / `assets/hero-bg.webp`: hero background.
- `assets/photo-original.jpg`: original owner photo you provided.
- `assets/logo-original.jpg`: original logo you provided.
